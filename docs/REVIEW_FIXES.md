Дополнительно: архивирование сотрудников сохраняет кадровую историю; защита последнего администратора учитывает актуальное состояние БД под блокировкой. Аналитика поддерживает SQLite и MySQL, включает месяцы с нулевыми значениями. Удалено диагностическое логирование персональных данных.

Оговорки: рабочие пароли и старые логины автоматически не меняются, чтобы сохранить существующий доступ. Очистка шаблона не отзывает секрет, если он ранее распространялся; замена пароля БД требует согласованного обновления сервера. Выбранная календарная политика отпуска описана в README. Онлайн-аудит CVE выполняется отдельно в разрешённой сетевой среде; обновление lock-файла само по себе не является подтверждением отсутствия уязвимостей.
